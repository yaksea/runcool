# 《跑酷酷》创新思考：横井军平视角

> 用横井军平（Game & Watch、Game Boy 理念、「枯燥技术的横向思考」）的思维方式，审视当前游戏可做的创新。  
> 对照文档：`游戏设计文档.md`  
> 核心不问「我们还能堆什么新技术」，而问「已有的简单零件，换个用法能不能变成新玩具？」

---

## 1. 横井式思维要点

| 原则 | 含义 |
|------|------|
| 枯燥技术的横向思考 | 用不新鲜、便宜、已验证的技术，组合出新鲜玩法 |
| 限制即创意 | 按键少、画面素、规则短，反而逼出清晰乐趣 |
| 玩具思维 | 先问「拿在手里想不想拨弄」，再问「像不像大作」 |
| 一种硬件多种游戏感 | 同一套输入，切换规则就换一种游戏 |
| 人人能懂 | 祖母也能在一分钟内明白怎么玩 |
| 耐用的简单 | 机制要少到能被彻底玩熟，又因组合而不腻 |
| 便携心智 | 体验适合短会话、可中断、负担低（不必真做掌机） |

---

## 2. 对《跑酷酷》的诊断

| 横井常问 | 现状 |
|----------|------|
| 最少按键时是否仍成立？ | 键位偏多（移动、跳、互动、攻击、技能、背包、暂停） |
| 是否在用「新内容」掩盖「旧零件没玩透」？ | 机关与敌人种类已不少，单零件深度与横向复用未必够 |
| 技术是否超过乐趣所需？ | Web + 横版物理已足够；创新不必上复杂模拟 |
| 能否用同一套物件做出另一种玩法？ | 目前基本只有「到旗子」一种读法 |
| 短时间拿起是否成立？ | 单关时长健康；菜单与系统层略重（商店 / 背包 / 多武器） |

**结论**：横井会建议——**做减法与横向复用**，而不是继续加枪、加怪、加技能。

---

## 3. 创新方向

### 3.1 横向思考：把已有零件「转 90 度」

不新增实体，只改用法：

| 已有零件 | 常规用法 | 横向新用法 |
|----------|----------|------------|
| 传送带 | 带路 | 当作「移动射击平台」；或整关只有传送带地面的节拍跑 |
| 风扇 | 上升 | 横向吹（已有弹簧可对照）、对吹形成「空中站立点」 |
| 碎裂平台 | 陷阱 | 变成唯一的「一次性加速板」——踩裂瞬间给前冲 |
| 定时平台 | 躲闪 | 变成整关唯一光源 / 唯一安全拍，像 Game & Watch 的时钟节奏 |
| 拉杆 | 开门 | 一杆多模：短拨 / 长拨出不同档（仍是一个 X） |
| 跷跷板 | 弹飞 | 双人想象中的天平：用敌人体重压一头（单机则用可推箱） |
| 传送门 | 旅行 | 「两个口的管道玩具」：只研究进出节奏的微型关 |
| 金币 | 商店货币 | 关内「节拍器」：按固定间隔吃币保持连走（吃币变节奏游戏） |
| 检查点 | 重生 | 可手动安置的「一根针」——限制携带数量，变成资源 |

横井式创新的判准：**没增加美术骨干类型，却增加了一种玩法句式。**

### 3.2 「Game & Watch 化」：一关一种玩具

把部分关卡（或挑战模式）收成极端简单规则：

| 微型模式名 | 规则（极简） | 复用零件 |
|------------|--------------|----------|
| 只有跳 | 不能攻击，只能踩与躲 | 史莱姆、弹板 |
| 只有拍 | 世界按统一节拍亮灭，移动必须合拍 | 定时平台、间歇泉 |
| 只有杆 | 全程靠拉杆改变地形前进 | 门、风扇、传送带 |
| 只有门洞 | 地图由 2～3 对传送门构成 | 传送门 |
| 持旗跑 | 终点旗可拔起带走，旗在身上时跳高低不同 | 旗帜（现有目标物） |

主线 8 关仍可丰富；**挑战房**用横井哲学做「一种玩具玩到透」。

### 3.3 输入减法：让「少键」成为特色模式

横井热爱限制。

- **单键跑酷周**：自动向右（或沿路径），玩家只负责跳（及可选的一次性技能）。  
- **无攻击周**：收起 J，强制走位与踩踏——重新发现已有敌人作为移动障碍物的价值。  
- **无技能周**：关掉 K，证明关卡在「裸方块」时仍公平有趣。  

这些模式几乎不增加资产，却能延长寿命，并检验设计是否依赖冗余系统。

### 3.4 用「旧技术」做出新体验（贴合本项目）

项目已是 Phaser 小体量网页游戏——这本身就很横井：

| 不做的（过度技术） | 可做的（横向） |
|--------------------|----------------|
| 布娃娃、流体、程序化大世界 | 两帧动画的果冻形变再夸张一点，玩具感更强 |
| 复杂 AI 导航 | 敌人只做「巡逻 + 一种反应」，靠关卡摆位出花样 |
| 联网共建 | 本地「幽灵竞速」：跟上周自己的影子跑 |
| 物理材质编辑器 | 三种地面摩擦系数：果冻 / 冰（复用传送带手感）/ 砂 |

**口号**：技术预算花在「手感帧」与「节奏」，不花在「看起来很次世代」。

### 3.5 人人能懂的信息设计

- HUD 可切换「简明档」：只显示心与旗的方向点。  
- 武器过多时，提供「推荐一键装备」：本关只需一种枪。  
- 商店文案继续短句（已有「K：短时……」风格，宜保持）。  
- 颜色盲友好：传送门配对不只靠色相，加简单符号（○ / △）。  

### 3.6 耐用简单：加深「动词」，而不是加长「名词列表」

横井会优先挖深这些动词：

1. **跳**（含二段、土狼、预输入——已有，宜做成系列关的主题变奏）  
2. **踩**  
3. **拨（X）**  
4. **被弹**（板 / 弹簧 / 跷跷板）  
5. **乘风**（风扇 / 泉）  

建议：每做一款新敌人或新武器前，先问「能否用旧动词新摆位解决？」  
刺球已实现却未投放——横井会说：先投放并做 2 个「只围绕不可踩」的微型挑战，再考虑第 11 种敌人。

### 3.7 便携心智：短会话与可中断

- 「一关挑战」从菜单直达，跳过多余叙事板。  
- 继续游戏已具备——可再加「30 秒玩具箱」：进门就是一个弹板 + 一个风扇的沙坑，无失败计数。  
- 暂停恢复要零摩擦（已有 P 菜单，保持简洁）。  

---

## 4. 旗舰提案：方块 & Watch（挑战选集）

做一组 **8 个微型玩具关**（可与主线 8 关分列）：

- 每关标题像 Game & Watch：`BALL`、`FLAG`、`FAN`、`GATE`…  
- 每关只突出 **1 个零件 + 1 个动词**  
- 统一用最少按键方案（例如仅方向 + 跳，或仅跳）  
- 通关解锁主线外观的「素色版 / 像素描边版」——用旧表现手法做新鲜奖励  

主线负责冒险感；选集负责横井式纯粹玩具感。两者共用资源，开发成本低、理念反差强。

---

## 5. 不应做的事（横井滤镜）

- 为了差异化去上重型技术或重剧情  
- 键位与系统持续膨胀（背包、技能、武器同时抢注意力）  
- 同屏新元素过多，导致「简单零件」看不清  
- 用数值膨胀代替规则创意  
- 抄大作系统而丢掉「拨弄一下就笑」的玩具内核  

---

## 6. 小步落地（按改动量）

1. **投放刺球 + 2 个微型挑战关**（横向用足已有敌人）  
2. **「只有跳」挑战模式**：禁用攻击与技能，复用旧关卡布局微调  
3. **定时平台 / 间歇泉世界节拍模式**：一关一种时钟玩具  
4. **HUD 简明档 + 本关推荐武器**：降低认知噪音  
5. **幽灵竞速（对战自己）**：几乎零新美术的长留存玩法  

---

## 7. 设计宣言

> 真正的进步，往往是把大家都看不上的旧零件，玩出别人没想到的新用法。

《跑酷酷》已有足够「枯燥而可靠」的积木：跳、踩、杆、风、带、门、泉。横井路线的创新，是**克制新增名词，拼命横着复用动词**——用限制做出清澈、好懂、想再拨弄一次的方块玩具。
