# 《跑酷酷》游戏设计文档

> 面向玩法与内容设计，不含技术实现细节。  
> 版本对应当前可玩内容（8 关）。

---

## 1. 一句话定位

**《跑酷酷》**是一款 **2D 横版平台跳跃 + 轻量战斗** 游戏。玩家操控一枚 Q 弹可变造型的小方块，在明亮户外世界中跑跳、躲障、打怪，抵达终点旗帜。

| 项目 | 说明 |
|------|------|
| 名称 | 跑酷酷 |
| 副标题 | Q 弹小方块的侧视冒险 |
| 类型 | 横版平台 / 跑酷 / 轻战斗 |
| 气质 | 卡通扁平、天空蓝→薄荷绿、暖橙主角、果冻形变手感 |
| 叙事 | 无独立剧情线；乐趣来自路线结构与机关组合 |

---

## 2. 核心体验目标

1. **跑跳优先**：平台节奏、高度差、折返路线是主菜。
2. **战斗为辅**：武器与踩踏用于清路，不是刷怪养成。
3. **低挫败重试**：无命数上限；死了回检查点满血再来。
4. **收藏与个性**：金币买外观与技能；武器进背包可跨关使用。
5. **星级挑战**：通关后追求少死 + 速通，形成重玩动机。

---

## 3. 核心循环

### 3.1 单局循环

1. 选关或「继续游戏」进入关卡  
2. 从起点跑跳穿越平台与机关  
3. 拾取金币、武器；用攻击或踩踏处理敌人  
4. 激活检查点；受伤/坠落后在检查点重生  
5. 触碰终点旗帜 → **过关** → 获得 1～3 星  
6. 选择下一关 / 再玩一次 / 返回菜单  

### 3.2 长期循环

1. 线性通关解锁下一关（共 8 关）  
2. 关卡金币进入全局钱包 → 商店购买外观与技能  
3. 关卡拾取的武器永久进入背包，可跨关装备  
4. 记录每关最佳星级与用时；支持「继续游戏」中途存档

## 4. 操作说明

开局（第 1 关）会提示：

> A/D 移动，空格跳，X 互动，J 攻击，K 技能，B 背包，P 暂停

| 按键 | 功能 |
|------|------|
| A / D 或 ← / → | 左右移动 |
| 空格 | 跳跃；在梯子上为跳离梯子 |
| W / ↑ | 非梯子时可跳跃；梯子上向上爬 |
| S / ↓ | 梯子上向下爬 |
| J | 攻击 |
| K | 使用已装备技能（商店购买） |
| X | 互动（破坏方块 / 操控拉杆） |
| B | 打开 / 关闭背包 |
| P | 暂停 |

### 4.1 内置移动能力（无需商店）

- **二段跳**：空中可再跳一次（力度略低于一段跳）  
- **土狼时间**：刚离地后短时间内仍可起跳  
- **跳跃预输入**：落地前短时间按跳，落地立即起跳  
- **爬梯子**：可沿梯子上下；空格跳离  
- **弹板**：踩上大幅跳高  
- **侧向弹簧**：水平弹射并带小跳  
- **跷跷板**：站上会倾斜，尖端可弹飞  
- **风扇 / 间歇泉**：提供上升气流  
- **传送门**：成对瞬移（有冷却，防连环误触）  
- **移动平台 / 传送带**：带位移动；传送带可用拉杆反转  

### 4.2 商店技能（K 键，同时只能装备 1 个）

| 技能 | 价格 | 冷却 | 持续 | 效果 |
|------|------|------|------|------|
| 无技能 | 0 | — | — | 可卸下技能 |
| 瞬移 | 15 | 2.8 秒 | — | 朝面向方向短距瞬移，短暂无敌 |
| 加速 | 18 | 4.5 秒 | 2.8 秒 | 短时大幅提高移速 |
| 飞行 | 22 | 5.0 秒 | 2.6 秒 | 短时取消重力，八向自由飞行 |

技能描述：

- 瞬移：K：向前短距瞬移  
- 加速：K：短时大幅加速  
- 飞行：K：短时自由飞行  

未装备技能时按 K 会提示：「未装备技能，去商店看看吧」。

## 5. 生存与战斗规则

### 5.1 玩家生命

| 属性 | 规则 |
|------|------|
| 生命 ❤ | 最大 3；**不会自动回复** |
| 护甲 ◆ | 最大 3；低于上限时每 **10 秒** 自动 +1 |
| 受击结算 | **先扣 1 护甲，护甲为 0 再扣 1 生命** |
| 受击无敌 | 约 0.8 秒（角色半透明闪烁） |
| 死亡条件 | 生命归零，或坠入地图底部深渊 |
| 重生 | 回到最后检查点（无则回到起点）；**生命与护甲全满**；短时额外无敌 |
| 命数 | **无传统命数**，可无限重试 |

伤害来源：敌人接触、尖刺、喷吐怪弹道、坠落深渊。

### 5.2 敌人伤害模型

- 敌人有「命中格」血条（显示为 `剩余/最大`）  
- **每次武器成功命中固定扣 1 格**（散射弹一发射出 3 颗，整次也只结算 1 格）  
- **踩踏**：从上方落下踩中 → **一击必杀**（刺球除外）  
- 刚被枪击后的敌人有短暂踩踏免疫，避免「跳着开枪」被误判成踩踏秒杀  

### 5.3 武器

武器**不在商店出售**，仅在关卡中拾取；获得后永久进入背包，可跨关使用。  
背包 6 槽：徒手 + 5 种武器；未获得的显示锁定。已拥有再拾取会提示「已拥有，已切换装备」。

| 武器 | 类型 | 特点 | 冷却约 |
|------|------|------|--------|
| 徒手 | 近战 | 默认；范围最短 | 320 ms |
| 弹力拳套 | 近战 | 范围中等，手感轻快 | 280 ms |
| 重锤 | 近战 | 范围最长，节奏偏慢 | 360 ms |
| 弹珠枪 | 远程 | 单发弹珠，射速快 | 260 ms |
| 火球术 | 远程 | 单发火球，体积较大 | 380 ms |
| 散射弹 | 远程 | 三颗扇形弹丸 | 420 ms |

拾取提示示例：「获得弹力拳套！已放入背包」。

## 7. 机关与场景元素

### 7.1 伤害 / 危险

| 元素 | 规则 |
|------|------|
| 尖刺 | 触碰即受击 |
| 深渊 | 掉出地图底部 → 计 1 次死亡，检查点满血重生 |
| 刺球 | 只能用武器打，不能踩 |

### 7.2 平台与移动装置

| 元素 | 规则 |
|------|------|
| 普通平台 | 固体立足点 |
| 移动平台 | 水平或垂直往复 |
| 碎裂平台 | 站上后短暂抖动 → 消失 → 一段时间后重生 |
| 定时平台 | 亮 / 灭循环；熄灭前会闪烁预警 |
| 弹板 | 大幅跳高 |
| 跷跷板 | 物理倾斜，可借力弹飞 |
| 传送带 | 带位移动；拉杆可反转方向 |

### 7.3 环境机关

| 元素 | 规则 |
|------|------|
| 梯子 | 垂直攀爬 |
| 风扇 | 上升气流；拉杆可开关 |
| 间歇泉 | 周期性向上喷发 |
| 侧向弹簧 | 水平弹射 |
| 传送门 | 成对传送；重生后短时禁用防误触 |

### 7.4 互动机关（X 键）

| 元素 | 提示 | 规则 |
|------|------|------|
| 可破坏方块 | 按 X 破坏 | 需敲击 1～2 次；一段时间后重生 |
| 拉杆 | 按 X 操控 | 切换关联的门 / 传送带 / 风扇 |
| 门 | — | 关闭时挡路；打开后可通过 |

成功反馈：「机关已破坏！」「机关已切换！」

### 7.5 收集物

| 元素 | 规则 |
|------|------|
| 金币 | 默认 1；部分为 2 或 3；计入全局钱包 |
| 武器箱 | 拾取入背包并自动装备 |

## 8. 关卡设计

### 8.1 统一目标

**抵达终点旗帜即过关。**  
不要求清怪、不要求集齐金币。

### 8.2 关卡一览

| 关 | 主题 | 路线结构 | 检查点 | 3★ 时限 | 2★ 时限 | 本关武器 | 金币总价值 |
|----|------|----------|--------|---------|---------|----------|------------|
| 1 | 台阶教学 | 先右后上，终点在高台 | 3 | 45 秒 | 75 秒 | 拳套 | 11 |
| 2 | 悬崖下行 | 高处出发，终点在谷底 | 3 | 55 秒 | 90 秒 | 拳套、弹珠枪 | 11 |
| 3 | 折返走廊 | 冲到尽头再爬回，终点在起点上方 | 5 | 70 秒 | 110 秒 | 弹珠枪、重锤 | 15 |
| 4 | 竖井攀升 | 窄而高，终点在塔顶 | 4 | 60 秒 | 95 秒 | 重锤、弹珠枪、火球 | 15 |
| 5 | 峡谷坠落 | 先右后下，终点在深层洞穴 | 4 | 75 秒 | 120 秒 | 散射、火球、重锤 | 15 |
| 6 | 环状回廊 | 绕一圈，终点在起点左后高台 | 4 | 80 秒 | 125 秒 | 散射、火球、重锤 | 13 |
| 7 | 山脊之字 | 反复上下，终点在远端低谷 | 5 | 90 秒 | 140 秒 | 散射、火球、重锤、弹珠枪 | 14 |
| 8 | 迷宫终章 | 多向岔路（含假路线），终点藏中央偏下 | 6 | 110 秒 | 170 秒 | 全套（含双火球） | 18 |

全 8 关金币总价值约 **112**（若全部收集）。

### 8.3 难度曲线

1. **第 1 关**：教学——台阶、梯子、单种敌人；弹出完整操作说明  
2. **第 2～3 关**：高度差、折返、第二种武器与追击敌人  
3. **第 4 关**：竖井 + 门/拉杆/破坏三件套 + 飞行敌人  
4. **第 5～6 关**：长图、传送门、坦克、多路径  
5. **第 7 关**：之字形长图，敌人与武器种类拉满  
6. **第 8 关**：迷宫 + 假路线 + 最高敌人密度；3 星要求 110 秒内且死亡 ≤ 1  

机关复杂度大致：早关以梯子/传送带/碎裂/风扇为主；中后期加入移动台、定时台、间歇泉、传送门与多拉杆组合。

### 8.4 解锁规则

- 初始仅解锁第 1 关  
- 通关第 N 关 → 解锁第 N+1 关  
- 关卡选择显示：`第 N 关` + 星级，或「未解锁」

## 9. 评分与进度

### 9.1 星级评价

过关时根据**用时**与**死亡次数**结算：

| 星级 | 条件 |
|------|------|
| ★★★ | 用时 ≤ 该关 3 星时限 **且** 死亡 ≤ 1 |
| ★★☆ | 用时 ≤ 该关 2 星时限 **且** 死亡 ≤ 5 |
| ★☆☆ | 其余通关情况 |

过关界面显示：过关！、用时、死亡次数、评价（★/☆）。

### 9.2 检查点

- 靠近自动激活，提示「检查点已激活」  
- 死亡后回到最后激活的检查点  
- 设计意图：检查点附近相对安全，避免重生即被围杀  
- 「继续游戏」可保留：关卡、检查点、用时、死亡数、当前武器等  

### 9.3 商店与经济

主菜单 →「商店」。**形状与颜色可自由搭配。**

| 天空蓝 | 12 |
| 薄荷绿 | 12 |
| 葡萄紫 | 18 |
| 阳光金 | 22 |

#### 形状

| 名称 | 价格 |

#### 技能

见 [4.2 商店技能](#42-商店技能k-键同时只能装备-1-个)。全部付费外观 + 技能买齐约需 **189** 金币（超过单周目全收集金币，鼓励多周目或精打细算）。

金币不足提示：「金币不足」。

### 9.4 存档内容（玩家可感知）

- 已解锁最高关卡  
- 全局金币  
- 武器背包与当前装备  
- 已拥有 / 已装备的外观与技能  
- 每关最佳星级与最佳用时  
- 进行中的关卡进度（继续游戏）  
- 「清除存档」需二次确认：「确定清除全部进度？」

## 10. 界面与反馈（玩家视角）

### 10.1 主菜单

- 标题「跑酷酷」+ 副标题  
- 金币显示  
- 按钮：继续游戏（有进度时）/ 开始游戏·选择关卡 / 商店 / 清除存档  
- 底部操作提示；背景展示当前角色（轻微浮动）  

### 10.2 游戏中 HUD

- 第 N 关  
- 时间 / 死亡 / 金币（全局）  
- 生命 ❤ / 护甲 ◆  
- 武器 / 技能（含冷却）  
- 背包快捷提示  

### 10.3 其他面板

| 场景 | 内容 |
|------|------|
| 暂停（P） | 已暂停 → 继续 / 重新开始 / 返回菜单 |
| 背包（B） | 点击切换武器；空背包提示去关卡拾取 |
| 过关 | 评价与下一关 / 再玩一次 / 返回菜单 |

| 底部互动条 | 「按 X 破坏」/「按 X 操控」 |

### 10.4 手感反馈

- **视觉**：落地压扁 / 起跳拉伸；受击闪白与微震；瞬移/死亡闪白；敌人血条与飘字；死亡压扁消失  
- **听觉**：芯片风短音效（跳跃、攻击、技能、机关等）；无独立 BGM 曲目要求

## 12. 设计原则小结

1. **第一性**：核心乐趣是「跑得顺 + 路线有惊喜」，战斗与商店服务于探索与个性表达。  
2. **低门槛高上限**：能过关很容易；三星（少死 + 速通）需要路线熟练与风险控制。  
3. **成长不破坏节奏**：武器永久解锁、技能可选装备，避免关卡内复杂养成。  
4. **机关递进**：每关引入有限新元素，终章做组合与迷宫压迫感。  
5. **个性化正交**：形状 × 颜色自由搭配；技能三选一，避免数值膨胀。
